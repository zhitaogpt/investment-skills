## 一、执行摘要

### 1.1 板块定性
PCB行业当前处于**AI算力驱动的二轮加速期**。第一轮(2024-2025H1)由GB200/GB300拉动，主要受益方为高多层板+M6/M7 CCL厂商；第二轮(2026-2028)由NVIDIA Rubin(VR200) → Rubin Ultra(NVL576) → Feynman平台拉动，**单rack PCB价值量从GB300的$3.5万跃升至VR200的$11.7万(+233%)**，并新增Midplane(44层)、Orthogonal Backplane(78层)等全新品类。

### 1.2 核心结论
| 维度 | 判断 |
|---|---|
| 行业景气 | 2026-2027强，2028后CPO+产能释放双重压力 |
| 估值水平 | TTM PE区间60-180x，板块整体已price-in 2026业绩，2027为关键验证窗口 |
| 投资节奏 | 短期等回调(板块涨幅普遍200-500%已透支)，中期分批建仓优质龙头 |
| 组合策略 | 核心(胜宏/沪电) + 卫星(生益/南亚弹性) + 观察(深南FC-BGA独立逻辑) |
| 风险等级 | 中高 — 单一客户依赖、产能过剩、CPO替代、估值高位 |

## 二、Robin/Rubin vs GB300 PCB BOM扩张 — 行业核心驱动

### 2.1 NVIDIA算力平台路线图
```
2024 GB200(Blackwell) → 2025 GB300(Blackwell Ultra) → 2026Q4 VR200(Rubin) → 2027 Rubin Ultra(NVL576) → 2028 Feynman
```

### 2.2 单Rack PCB BOM对比(关键数据)
| 项目 | GB200 NVL72 | GB300 NVL72 | VR200 NVL144 | Rubin Ultra NVL576 |
|---|---|---|---|---|
| 计算密度 | 72 GPU | 72 GPU | 144 GPU | 576 GPU |
| 单rack PCB价值 | ~$22K | ~$35K | **~$117K** | ~$280K+ |
| 主板层数 | 22层 | 26层 | **40+层** | 60+层 |
| CCL等级 | M6/M7 | M7/M8 | **M8主流** | **M9** |
| HDI阶数 | 4阶 | 5阶 | **6阶** | 6+阶 |
| 新增组件 | - | - | **Midplane 44层** | **Orthogonal Backplane 78层** |
| 单卡PCB价值 | $305 | $486 | **$813** | $486+ |

### 2.3 BOM扩张三大维度
**① 层数升级 (22→78层)**：Rubin Ultra NVL576引入Orthogonal Backplane(正交背板)，单板78层，价值量是GB300主板的3-5倍。

**② CCL升级 (M6→M9)**：M9级CCL Df值≤0.0015@10GHz，对树脂体系/玻纤布/铜箔表面处理全面升级，单价较M6翻倍以上。**全球M9认证厂商仅5家**：松下、台光电、生益科技(中国唯一)、Isola、EMC。

**③ 新增品类**：
- **Midplane(中板)**：连接Compute Tray和Switch Tray，单rack 1块，44层，单价$3000-5000
- **Orthogonal Backplane(正交背板)**：Rubin Ultra独有，单rack 1块，78层，单价$8000-12000
- **CPO Substrate(光电共封基板)**：2027+渗透，替代部分传统PCB(中长期负面)

### 2.4 受益排序
```
M9 CCL(生益独占) > Orthogonal Backplane(尚无明确国内厂商) > 
40+层超高层板(胜宏/沪电) > Midplane(沪电主攻) > HDI升级(胜宏/深南)
```

### 4.1 胜宏科技(300476.SZ) — 计算板王者，等待回调

**多头**：1Q2026收入+53.91%/利润+62.90%超预期，NVL72互联板+Midplane双轮驱动，AI PCB ~40%份额
**空头**：估值PE 70x偏高，2027 CPO渗透或冲击传统Switch板需求
**操作**：现价128.29，回调至110-115分批，第一目标145，止损105

### 4.3 深南电路(002916.SZ) — FC-BGA国产替代，独立逻辑
**多头**：2026Q1收入+37.9%/利润+73.0%，FC-BGA全国冠军、AI/存储/CPU基板国产替代独立赛道

**空头**：① TTM PE 130-180x极致高估；② 客户高度集中(前五大客户>70%)；③ 市值470亿相对营收/利润支撑薄弱

## 七、风险因素

### 7.1 行业层面(高优先级)
1. **CPO替代风险**：2028后光电共封技术若提前商用，将替代部分传统PCB需求，影响10-15%板块估值中枢
2. **产能过剩**：板块8家厂商2025-2027合计资本开支400亿+，2027-2028产能集中释放，价格战风险
3. **NVIDIA订单集中度**：所有公司AI业务高度依赖NVIDIA一家客户

### 7.2 公司层面(差异化风险)
- **胜宏**：管理层减持、业绩不及预期
- **沪电**：CPO替代传统Switch板
- **深南**：FC-BGA爬坡进度
- **生益**：M9认证份额被海外竞争对手稀释
- **南亚**：客户集中度风险、估值透支

### 7.3 宏观与政策
- 中美科技摩擦升级、出口管制扩大至PCB领域
- 人民币汇率大幅波动影响出口型厂商利润
