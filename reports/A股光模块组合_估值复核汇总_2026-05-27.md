## 五、关键风险预警

### 5.1 板块系统性风险

1. **AI Capex 增速回归**：2026 +67-94% 是不可持续的峰值，2027 增速回归至 30-40% 将引发整板块估值压缩
2. **DCF 与 PE 的认知分歧**：当前所有标的 DCF 中性档均显著低于现价，反映"标准模型 vs 主题投资"的根本矛盾——若市场对 AI 长期叙事产生怀疑，回调可能剧烈
3. **海外溢价收敛**：A股龙头若被发现盈利质量低于海外可比（如天孚的扣非问题），PE 收敛至海外水平意味着 **30-50% 的回调**
4. **铜缆延寿**：Broadcom 和 Jensen Huang 均表态"尽可能长地用铜缆"，CPO 商业化节奏可能慢于预期，直接利空天孚、太辰光

### 5.2 个股特定风险

| 标的 | 关键风险触发点 |
|------|---------------|
| 中际旭创 | 北美客户 Capex 下修；存货周转放缓（已增 105%） |
| 新易盛 | Q2 环比若仍下滑 → 增长故事破裂 |
| 天孚通信 | Q2 扣非若持续与归母背离 → 盈利质量重估 |
| 源杰科技 | Q2 业绩若不及 Q1 年化 → 估值崩塌 50%+ |
| 仕佳光子 | OCF 若持续负值 + 存货减值 → 财务质量恶化 |

## 七、最终建议

### 给保守投资者的建议
**当前不建议在 A 股光模块板块建仓**。所有5只标的均处于合理价值上沿或显著高估区间。等待板块整体回调 **20-30%**（中际旭创 < 850、新易盛 < 550、天孚 < 350、源杰 < 280、仕佳 < 100）后再分批介入。

### 给激进投资者的建议
若必须配置，仅推荐 **中际旭创 + 新易盛** 组合（共25%仓位），它们是5只中估值最接近海外可比的标的，下行空间相对有限。**严格避免源杰科技和仕佳光子**——光芯片板块的估值泡沫风险最高。

### 给已持仓投资者的建议
- 单只浮盈 > 50%：建议止盈 30-50%
- 单只浮盈 < 20%：建议持有但不加仓
- 持有源杰科技且浮盈 > 100%：强烈建议止盈大部分
