# A股光模块/光互联板块投资布局总报告

## 摘要 Executive Summary

**行业景气度：9/10（极度景气，趋势向上）**。2026年北美四大云厂商Capex合计超6,500-7,250亿美元（+67-94% YoY），叠加国内字节、阿里、腾讯加码，全球AI算力Capex首破1万亿美元仅一步之遥。英伟达Rubin平台将1.6T光模块/GPU配比从GB300的1:2-3提升至1:4-6，单计算单元所需可插拔光模块从216只跃升至约2,500只，需求曲线陡峭向上。1.6T供需缺口估计达40-50%，800G缺口22-27%，整个产业链处于"卖方市场"。

**配置框架（核心结论）**：

1. **整机厂首选中际旭创（300308）**：2026Q1营收195亿(+192%)、净利润57亿(+262%)、毛利率46%全面超预期；2026E PE 42x对应+174%净利增速，PEG仅0.24；估值低于海外可比（Coherent/Lumentum Forward PE 46-57x）。
2. **上游光芯片首选源杰科技（688498）**：A股最纯正的高端激光芯片IDM，2026Q1毛利率77.8%、净利润同比+1153%，弹性最大但估值最高；建议趋势跟随而非追高。
3. **CPO/平台型首选天孚通信（300394）**：盈利质量最优（毛利率56.6%、ROE 41.9%），CPO全产品线布局最完整，可插拔与CPO两个时代均受益。
4. **次选弹性新易盛（300502）**：2026E PE 38x为板块最低，但Q1环比下滑信号需Q2验证。
5. **风险标的**：光迅科技、太辰光、光库科技估值已严重透支（PE-TTM 100-356x）。

**组合建议**：进攻型（中际旭创30%+源杰科技20%+新易盛20%+天孚通信15%+仕佳光子10%+现金/对冲5%）；稳健型（中际旭创35%+天孚通信25%+源杰科技10%+新易盛15%+现金15%）。

## 第一部分：行业全景与景气度

### 1.1 需求侧：AI Capex 史无前例

**北美四大云厂商 2026 全年 Capex 指引**：

| 公司 | 2026E Capex | 同比 |
|------|-------------|------|
| Amazon | 2,000亿美元 | 维持最高水平 |
| Microsoft | 1,900亿美元 | 从1,200亿上调 |
| Alphabet | 1,800-1,900亿美元 | 从1,850亿上调 |
| Meta | 1,250-1,450亿美元 | 从1,150-1,350亿上调 |
| **合计** | **6,500-7,250亿美元** | +67-94% YoY |

加上Oracle、CoreWeave，六家全年Capex总额将破8,000亿美元，美银预计2027年破1万亿美元。国内字节2026年Capex计划超2,000亿元(+25%)，阿里、腾讯同步加码，国产算力链同步受益华为昇腾950订单。

**英伟达平台对光模块的拉动**：

- GB200 NVL72：800G 光模块 GPU:模块 = 1:3
- GB300 NVL72：1.6T 配比 1:2-3，单机架 216只1.6T等效模块
- Vera Rubin：1.6T 配比 1:4-6，单计算单元1.6T模块需求约2,500只（高盛 2026-04-17）

到2026年底全球AI GPU出货预计2,000万颗，直接转化为800G/1.6T光模块海量需求。

### 1.2 供给侧：紧张状态延续

- **800G**：2025年起量约750万只 → 2026年估计2,500-3,000万只，缺口22-27%
- **1.6T**：2025Q3起批量出货 → 2026年估计1,000-1,200万只，缺口40-50%
- **EML/CW激光芯片**：海外巨头(Lumentum/Coherent)产能订单已排至2027年后，供需缺口25-30%
- **TSMC COUPE 光子集成平台**：2027H1目标产能10K WPM

### 1.3 技术演进时间线

| 时间 | 关键节点 |
|------|----------|
| 2025Q4 | Broadcom Tomahawk 6 - Davisson(102.4Tbps CPO交换机)出货 |
| 2026H1 | NPO方案量产，作为CPO过渡 |
| 2026H2 | Nvidia Rubin NVL72/NVL144出货(铜缆为主) |
| 2027H1 | TSMC COUPE光子集成产能爬坡 |
| 2027H2 | Nvidia Rubin Ultra NVL576首次在scale-up使用CPO |
| 2028 | Nvidia Feynman NVL1152，Jensen表态"全面CPO" |
| 2028-2030 | CPO渗透率从低个位数升至35%+ |

**关键分歧点**：CPO真正scale-up商用要等2027H2-2028，此前仍是可插拔光模块的天下。Broadcom和Jensen Huang均表示"尽可能长地使用铜缆"，对CPO短期商业化节奏构成不确定性。

## 第五部分：催化与风险

### 5.1 中短期催化（3-12个月）

1. **二季报验证**：8月发布的2026Q2财报，重点关注新易盛环比是否回升、中际旭创毛利率是否站稳46%
2. **1.6T 大单落地**：北美客户1.6T确定性订单进一步释放
3. **Rubin平台节奏**：英伟达Rubin/Rubin Ultra发布与1.6T模块配套验证
4. **国产算力**：华为昇腾950订单及其配套国产光模块/光芯片放量
5. **CPO技术里程碑**：Nvidia GTC 2026 Spring（春季活动）的CPO技术更新

### 5.2 中短期风险

1. **美股Capex指引下修**：北美云厂商Q2/Q3财报若显著低于预期，整个板块估值回调
2. **地缘政治升级**：中美科技摩擦、出口管制扩展至光通信领域
3. **铜缆延寿**：scale-up继续用铜缆，1.6T需求短期内可能不及预期
4. **板块估值泡沫破裂**：CPO概念板块总市值3-4万亿元，部分标的估值严重透支
5. **价格下行**：光模块/光芯片供需紧张缓解后议价能力下降，毛利率均值回归

### 5.3 操作纪律

- **止损线**：单标的回撤超20%或基本面恶化（季度环比连续两期下滑），强制减仓
- **止盈线**：估值进入历史90%分位以上+增速指引下修，分批减仓
- **再平衡**：每季报后根据估值/业绩匹配度调整权重
- **对冲工具**：可配置板块ETF空头或券商雪球结构对冲尾部风险
