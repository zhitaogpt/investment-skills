# 储能市场深度调研报告

> 调研日期：2026年4月29日

---

## 一、全球能源市场结构总览

### 1.1 一次能源消费结构（2024年）

| 能源类型 | 全球占比 | 趋势 |
|---------|---------|------|
| **石油** | **31-34%** | 增速放缓至0.8%，仍为第一大能源 |
| **煤炭** | **27-28%** | 达165EJ历史新高，83%集中亚太 |
| **天然气** | **23-25%** | 增长2.5-2.7%，亚洲驱动 |
| **水电** | **6-7%** | 增长4.4% |
| **核能** | **~4%** | 增长近4% |
| **风电+太阳能** | **~5%** | 增长16%，贡献新增发电量的53% |

**核心结论**：化石能源仍占全球一次能源的81-87%，但可再生能源贡献了能源增量的38%（最大份额）。全球处于"多能源并行扩张的过渡期"。

### 1.2 能源增量贡献结构（2024年）

- **可再生能源**贡献增量的 **38%**（最大份额）
- **天然气**贡献 **28%**
- **煤炭**贡献 **15%**
- **石油**贡献 **11%**
- **核能**贡献 **8%**

非化石能源已占据能源增量的近一半（46%），但化石能源需求仍在同步增长。

### 1.3 中国能源消费结构（2024-2025年）

| 能源类型 | 2024年占比 | 变化趋势 |
|---------|----------|---------|
| 煤炭 | 53.2% | 年降1.5个百分点 |
| 石油 | ~17-18% | 下降，2025年被非化石能源超越 |
| 天然气 | ~9% | 上升 |
| 非化石能源 | ~20-21% | **2025年超过石油，成为第二大能源** |

**里程碑**：2025年风电光伏装机首次超越煤电，非化石能源消费超过石油。

### 1.4 全球电力结构演变（2020-2024）

| 年份 | 可再生能源发电占比 | 风光发电占比 | 低碳能源总发电占比 |
|------|------------------|------------|------------------|
| 2020 | 约29% | 约9.5% | 约37% |
| 2021 | 约28% | 约10.3% | 约37% |
| 2022 | 约29.1% | 约12% | 约39% |
| 2023 | 约30% | 约13.4% | 约39% |
| **2024** | **约32%** | **约15%** | **约40.9%** |

2024年清洁能源发电突破40%里程碑。2025年上半年可再生能源发电首次超过煤电成为最大电力来源。

## 二、储能市场规模与增长

| 指标 | 2024年 | 2025年 | 2030年预测 |

| 全球累计装机 | 372 GW | ~500 GW | -- |
| 全球储能投资 | ~400亿美元 | **710亿美元** | -- |
| CAGR（2022-2030） | -- | -- | **~30%** |

### 2.2 中国储能装机数据

| 指标 | 2024年 | 2025年 | 趋势 |
|------|--------|--------|------|
| 新型储能累计装机 | 73.76 GW / 168 GWh | **144.7 GW / 351 GWh** | 同比+85% |
| 新增装机 | 39 GW / 99 GWh | 66.43 GW / 189.48 GWh | 连续4年全球第一 |
| 占全球比重 | 40%+ | **47%** | 持续提升 |
| 产业市场规模 | ~2973亿元 | **~6800亿元** | 同比+42% |
| 等效利用小时数 | ~900小时 | **1195小时** | 利用率显著提升 |

"十三五"末至今增长超40倍，实现跨越式发展。

### 2.3 储能在能源市场中的占比

| 维度 | 占比 | 说明 |
|------|------|------|
| 占清洁能源投资 | **~3-5%** | 710亿美元 vs 2.2万亿美元清洁能源投资 |
| 占全球能源投资 | **~2%** | 710亿美元 vs 3.3万亿美元总能源投资 |
| 中国新型储能占电力装机 | **~5%** | 144.7GW vs ~3000GW总装机 |

**虽然占比小，但增速远超其他能源品类（CAGR 30%+ vs 整体能源增长2%）。**

## 三、储能技术路线格局

### 3.1 当前技术占比（2024年中国）

| 技术路线 | 装机占比 | 特点 |
|---------|---------|------|
| **磷酸铁锂电池** | **96.4%** | 绝对主导，成本持续下降 |
| 压缩空气储能 | 1.6% | 30万千瓦级项目已投运 |
| 铅蓄电池 | 0.9% | 传统技术 |
| 液流电池 | 0.5% | 商业化加速，CAGR约57% |
| 钠离子电池 | <1% | 2025年产业化拐点 |

### 3.2 技术发展趋势

- **锂电池**：电芯价格降至0.3-0.4元/Wh，储能系统中标价探至0.456元/Wh
- **长时储能加速**：2025年前11月长时储能并网11.52GW，占功率29%、容量44%
- **液流电池**：2025年1-9月新增41个项目，计划年产能61.7GWh，投资349亿元
- **2030年预测**：4小时以上储能装机占比达50%

## 四、储能产业链与竞争格局

### 4.1 产业链全景

```
上游（原材料/设备）          中游（制造/集成）           下游（应用）
├─ 正极材料：德方纳米        ├─ 电池：宁德时代           ├─ 电源侧（48%）
├─ 负极材料：贝特瑞          │  比亚迪、亿纬锂能         ├─ 电网侧（39%）
├─ 电解液：天赐材料          │  海辰储能、远景能源        └─ 用户侧（13%）
├─ 隔膜：恩捷/星源材质       ├─ PCS：阳光电源、科华数能
├─ BMS/EMS                   ├─ 系统集成：海博思创
└─ 设备：杭可/先导智能       │  中车株洲所、远景能源
                              └─ 温控/消防
```

### 4.2 竞争格局（2025年）

- **电池出货**：2025年全球表前侧储能电池出货507.9 GWh（同比+83%）
- **"一超多强"**：宁德时代主导，海辰储能、远景能源强势崛起
- 75家储能产业链上市公司总营收突破2万亿元
- **Top系统集成商**：中车株洲所、海博思创、远景能源等
- **海外出口**：2024-2025年中国企业海外订单近250 GWh，2025年新增海外订单366 GWh（同比+144%）

|------|------|
| **A股** | PE 15-30倍居多，业绩确定性强 |

## 五、政策驱动

### 5.1 中国政策

- **《新型储能规模化建设行动方案（2025-2027年）》**：发改委/能源局联合发布
- **取消强制配储**：2025年初重大政策调整，储能转向市场化驱动
- **利用率提升**：等效利用小时数从~900提升至1195小时
- **近30个省市**发布储能产值目标，总额超3万亿元

### 5.2 美国政策

- **IRA法案**：30% ITC投资税收抵免（延至2035年，2033年开始退坡）
- **众议院法案**：大储ITC补贴拟2029年开始退坡（存在不确定性）
- 加州、德州等州级政策大力推动

### 5.3 欧洲

- 2024年储能新增11GW/21GWh，大储同比+108%/+197%
- 俄乌冲突后户储需求先升后降（电价回落）

## 六、盈利模式与成本趋势

### 6.1 主要盈利模式

| 模式 | 说明 | 成熟度 |
|------|------|--------|
| 峰谷套利 | 低电价充、高电价放 | 已成熟 |
| 辅助服务 | 调频调峰补偿 | 逐步完善 |
| 容量租赁 | 独立储能电站出租容量 | 快速增长 |
| 现货市场套利 | 参与电力现货市场 | 试点中 |
| AIDC储能 | AI数据中心UPS+储能一体 | 新兴热点 |

### 6.2 成本趋势

- 锂电储能系统中标价：从2023年的0.8-0.9元/Wh -> 2025年的**0.45-0.5元/Wh**
- 电芯价格：降至0.3-0.4元/Wh
- 度电成本（LCOS）持续下降，储能经济性拐点已到来

## 七、风险与挑战

| 风险 | 说明 |
|------|------|
| **价格战加剧** | 系统中标价持续下探，行业洗牌加速 |
| **产能过剩** | 大量企业涌入，2025年"更加惨烈的洗牌" |
| **政策不确定性** | 美国IRA可能退坡，中国取消强配后需求结构变化 |
| **技术迭代风险** | 长时储能技术（液流、压缩空气）对锂电的替代 |
| **海外贸易壁垒** | 美国关税、OBBB法案对中国企业出口的影响 |
| **安全风险** | 电化学储能安全事故仍时有发生 |

## 八、投资结论

### 8.1 核心判断

| 维度 | 评估 |
|------|------|
| **行业增速** | CAGR 30%，确定性极高的高增长赛道 |
| **市场空间** | 2025年中国产值6800亿，2030年超3万亿 |
| **渗透率** | 储能占能源投资仅2-3%，巨大提升空间 |
| **经济性** | 成本持续下降，利用率提升，盈利拐点到来 |
| **政策支持** | 中美欧三大市场均有强政策驱动 |
| **竞争格局** | 行业洗牌期，龙头份额集中 |

### 8.2 投资方向建议

| 方向 | 推荐逻辑 | 代表标的 |
|------|---------|---------|
| **电池龙头** | 规模效应+出海能力 | 宁德时代、亿纬锂能 |
| **系统集成** | 出货量爆发+海外拓展 | 海博思创、阳光电源 |
| **逆变器/PCS** | 量增利稳，海外溢价 | 阳光电源、科士达 |
| **液流电池** | 长时储能商业化加速（CAGR 57%） | 关注液流电池企业 |
| **AIDC储能** | AI数据中心+储能新场景 | 双登股份 |
| **港股储能** | 估值洼地 | 思格新能、果下科技等 |

### 8.3 关键节奏

- **短期（2026）**：关注行业洗牌后龙头份额提升、海外订单兑现
- **中期（2027-2028）**：长时储能商业化、电力市场改革推动盈利改善
- **长期（2030+）**：储能从配角走向能源基础设施核心，3万亿产业规模
