# 港股IPO打新评估框架

## 一、华泰五维度量化打分模型

华泰证券构建的打分体系从市场情绪、公司基本面、发行特征三大维度出发，五个指标等权打分。选取2.5分以上标的参与可提高约15pct收益，3分以上标的破发率仅23%、平均收益44.2%。

### 指标1：近期行业指数表现（市场情绪）

- 行业近3个月涨幅越大，IPO打新收益越高
- 行业涨幅>30%时，后续IPO收益均值超50%
- **评分规则**：
  - 3分：行业近3月涨幅>30%
  - 2分：行业近3月涨幅10%-30%
  - 1分：行业近3月涨幅0%-10%
  - 0分：行业近3月下跌

### 指标2：近期打新平均收益（市场情绪）

- 近期新股开盘平均收益在20%-30%时效果最好
- 超过30%反而可能是拐点信号（过热）
- **评分规则**：
  - 3分：近期新股平均收益20%-30%
  - 2分：近期新股平均收益10%-20%
  - 1分：近期新股平均收益0%-10%或>30%
  - 0分：近期新股平均收益为负

### 指标3：相对估值——发行PE vs 行业PE（基本面）

- 估值溢价20%-40%的新股反而表现更好（通常是高增速科技/医药股）
- 未盈利公司通常也表现较好（增速预期快）
- **评分规则**：
  - 3分：未盈利或相对行业溢价20%-40%
  - 2分：相对行业折价或溢价<20%
  - 1分：相对行业溢价40%-60%
  - 0分：相对行业溢价>60%

### 指标4：发行定价价差（发行特征）

- 招股价上下限价差越窄，定价信心越强
- 价差超过20%的项目收益显著偏低
- **评分规则**：
  - 3分：定价价差<5%
  - 2分：定价价差5%-10%
  - 1分：定价价差10%-20%
  - 0分：定价价差>20%

### 指标5：基石投资者持股占比（发行特征）

- 有基石（均值涨12%）显著优于无基石（均值涨4.6%）
- 比例过高（>50%）反而走弱
- **评分规则**：
  - 3分：基石占比20%-40%
  - 2分：基石占比40%-50%或10%-20%
  - 1分：基石占比<10%或>50%
  - 0分：无基石投资者

### 综合评分与决策

| 总分（满分15，折合5分制） | 建议 |
|---|---|
| ≥3.0分 | 强烈推荐参与，历史破发率23%，平均收益44% |
| 2.5-3.0分 | 推荐参与，收益比不筛选高15pct |
| 1.5-2.5分 | 谨慎参与，需结合定性分析 |
| <1.5分 | 建议回避 |

## 二、基本面定性分析框架（"高增长行业的高增长稀缺龙头"）

### 四维度基本面筛选

1. **行业高增长**
   - 行业增速>15%，渗透率低，处于朝阳赛道
   - 行业空间大，政策支持

2. **行业龙头**
   - 市占率领先，与第二名拉开差距
   - 竞争壁垒强，最好是寡头/垄断格局

3. **公司高增长**
   - 盈利公司：利润增速 > 营收增速（盈利质量改善）
   - 亏损公司：营收快速增长 + 亏损率持续收窄

4. **业务稀缺性**
   - 难以复制的竞争壁垒
   - 毛利率高于行业平均
   - 稀缺标的更有估值弹性

### 量化筛选标准参考

| 指标 | 优秀标准 |
|---|---|
| 行业增速 | >15% |
| 公司营收增速 | >30% |
| 公司利润增速 | >营收增速 |
| 毛利率 | >行业平均或>30% |
| 市占率 | 行业前3 |

## 三、估值对标分析

### 方法选择

| 估值方法 | 适用公司类型 | 适用市场环境 |
|---|---|---|
| 市盈率(PE) | 盈利稳定公司 | 熊市/牛市前期最常用 |
| 市销率(PS) | 亏损成长型公司 | 仅牛市才受追捧 |
| 市净率(PB) | 重资产公司 | 银行/地产/公用事业 |
| EV/EBITDA | 高资本开支公司 | 通用 |

### 估值判断标准

- 对比同行业/同类型可比公司
- 优秀新股估值通常比行业均值高一些（机构看好）
- 高出行业均值30%以上 → 可能高估
- 低于或持平行业均值 → 估值合理/低估

## 四、发行结构与制度信号分析

### 正面信号

| 信号 | 说明 |
|---|---|
| 知名基石投资者 | 高瓴、淡马锡、GIC等参与，产生"认证效应" |
| 头部保荐人 | 中金、高盛、摩根士丹利等，护盘能力强 |
| 窄定价区间 | <10%，定价信心强 |
| 绿鞋机制 | 有绿鞋可稳定后市 |
| 基石占比20%-50% | 适度锁定，既有背书又不过度集中 |
| 回拨机制B | 散户份额确定（10%），降低破发概率 |
| 超额认购倍数高 | >100倍热度极高（事后指标） |

### 负面/警示信号

| 信号 | 说明 |
|---|---|
| 无基石投资者 | 机构信心不足 |
| 基石占比>50% | 可能是硬撑发行 |
| 定价价差>20% | 定价信心不足 |
| 小型不知名保荐人 | 护盘能力弱 |
| 未盈利+熊市 | 极高破发风险 |
| 上市前大幅缩减募资 | 市场需求不足 |

## 五、市场情绪与时机判断

### 宏观环境

- **弱美元 + 低Hibor**：一二级市场共振改善，打新环境最优
- **强美元 + 高Hibor**：流动性收紧，打新环境恶化
- **恒生指数走势**：大盘强势时新股表现的放大效应更强

### 打新市场周期

- 近期新股整体表现好 → 市场情绪热 → 正反馈循环
- 近期破发率上升 → 市场情绪冷 → 需更谨慎选股
- Q4及年末通常IPO密集，供给压力加大

### 行业历史表现（首日涨跌幅排名）

**表现较好**：耐用消费品、有色金属、日常消费零售、医药
**表现较差**：家电、石油石化、军工

## 六、入通（纳入港股通）预期评估

入通后南向资金持续增配（半年内持股占比中位数近3%），是重要的股价支撑力量。

### 入通路径

1. **快速纳入**：市值位于恒综成份股前10%（约2000亿），最快11个交易日
2. **AH股自动纳入**：股价稳定期后约1个月
3. **季度检讨纳入**：满足恒生综合指数标准（市值约90亿+）
4. **注意**：同股不同权公司无法快速入通

### 入通窗口投资机会

- 上市 → 入通期间：绝对收益中位数2%-10%，超额收益中位数3%-8%
- 入通后5-20个交易日：绝对收益和超额收益中位数转负（抢跑资金获利了结）
