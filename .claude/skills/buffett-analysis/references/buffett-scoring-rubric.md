# 巴菲特价值评分体系

> "投资就是今天投出去钱，为了在将来某一天收回更多的钱。" — 沃伦·巴菲特

## 评分总览

| # | 维度 | 权重 | 核心问题 | 来源原则 |
|---|------|------|---------|---------|
| 1 | 护城河持久性 | 20% | 竞争优势是否在扩宽？ | "我寻找被不可逾越的护城河保护的经济城堡" |
| 2 | 安全边际 | 15% | 当前价格低于内在价值多少？ | "投资中最重要的三个字" |
| 3 | 财务实力 | 15% | 资产负债表是否坚如磐石？ | 保守融资，低负债 |
| 4 | 盈利可预测性 | 12% | 未来5年盈利能否高度确定？ | "我不试图预测市场…我关注可预测性" |
| 5 | 管理层品质 | 10% | 管理层是否正直且理性配置资本？ | "我们看三点：智慧、精力、正直" |
| 6 | 定价权 | 8% | 能否在不流失客户的情况下提价？ | "评估企业最重要的单一决定就是定价权" |
| 7 | 增长质量 | 8% | 增长是否创造价值（ROIC>WACC）？ | 非所有增长有价值 |
| 8 | 商业可理解性 | 5% | 12岁小孩能否理解？ | 能力圈原则 |
| 9 | 护城河多样性 | 4% | 有几种护城河？ | 多重护城河更难被攻破 |
| 10 | 长期持有适宜性 | 3% | 20年后公司会更强吗？ | "最喜欢的持有期是永远" |

## 各维度评分标准

### 1. 护城河持久性（20%）

| 分数 | 描述 | 标杆 |
|------|------|------|
| 9-10 | 护城河极宽且在持续扩宽，几乎不可能被颠覆 | Visa/Mastercard支付网络、贵州茅台品牌 |
| 7-8 | 护城河宽阔且稳定，短期无被颠覆风险 | 可口可乐、苹果生态 |
| 5-6 | 有一定护城河但面临侵蚀压力或新进入��威胁 | 传统银行、大型零售商 |
| 3-4 | 护城河狭窄，竞争优势可能在3-5年内消失 | 普通品牌消费品 |
| 1-2 | 几乎无护城河，完全竞争市场 | 大宗商品生产商、航空公司 |

**护城河类型评估子表**（每类0-3分）：

| 护城河类型 | 0分 | 1分 | 2分 | 3分 |
|-----------|-----|-----|-----|-----|
| 品牌 | 无品牌溢价 | 区域性品牌 | 全国性强品牌 | 全球性不可替代品牌 |
| 网络效应 | 无 | 轻微 | 显著但可被替代 | 赢家通吃 |
| 转换成本 | 几乎为零 | 有成本但可管理 | 高成本 | 极高，接近不可能 |
| 成本优势 | 无 | 轻微规模效应 | 显著规模/流程优势 | 结构性成本壁垒 |
| 监管/无形资产 | 无 | 有一些许可/专利 | 重要牌照或专利组合 | 垄断性牌照/特许权 |

### 2. 安全边际（15%）

| 分数 | 描述 |
|------|------|
| 9-10 | 股价低于内在价值50%以上（极度低估） |
| 7-8 | ���价低于内在价值30-50%（显著低估） |
| 5-6 | 股价低于内在价值10-30%（轻度低估） |
| 3-4 | 股价接近内在价值（±10%，合理估值） |
| 1-2 | 股价高于内在价值10%以上（高估，无安全边际） |

### 3. 财务实力（15%）

5项子指标，各2分，累加映射到1-10：

| 子指标 | 0分 | 1分 | 2分 |
|--------|-----|-----|-----|
| ROE一致性 | <10%或波动大 | 10-15%较稳定 | >15%连续5年以上 |
| 负债率 | D/E>1.0 | D/E 0.5-1.0 | D/E<0.5 |
| 净利率趋势 | 下降 | 稳定 | 稳定上升 |
| Owner Earnings增速 | <0% | 0-GDP增速 | >GDP+通胀 |
| FCF转化率 | <60% | 60-80% | >80% |

### 4. 盈利可预测性（12%）

| 分数 | 描述 |
|------|------|
| 9-10 | 过去10年每年盈利增长，波动<10%，行业需求刚性 |
| 7-8 | 过去10年仅1-2年下降，波动<20% |
| 5-6 | 盈利大方向向上但周期波动明显（20-40%） |
| 3-4 | 盈利波动大或有亏损年份 |
| 1-2 | 盈利高度不可预测、频繁亏损或依赖单一客户/项目 |

### 5. 管理层品质（10%）

3项子指标，各按0-3分评估：

| 子指标 | 评估内容 |
|--------|---------|
| 正直/品格 | 有无丑闻、诚信记录、信息披露质量 |
| 资本配置 | 回购/分红纪律、并购ROI、不乱烧钱 |
| 股东对齐 | 管理层持股比例、薪酬合理性、少发期权 |

芒格特别强调："避免品格有问题的人。"管理层品格有重大疑问 → 直接扣到3分以下。

### 6. 定价权（8%）

| 分数 | 描述 | 标杆 |
|------|------|------|
| 9-10 | 可定期提价，客户无替代选择 | 茅台、爱马仕、Visa |
| 7-8 | 可提价但需谨慎，有一定替代品 | 苹果、星巴克 |
| 5-6 | 部分产品有定价权，部分面临价格竞争 | 大型消费品公司 |
| 3-4 | 定价权有限，客户价格敏感 | 电商零售、快时尚 |
| 1-2 | 完全价格接受者，受市场/大宗商品定价 | 航空、钢铁、农产品 |

### 7. 增长质量（8%）

| 分数 | 描述 |
|------|------|
| 9-10 | 高ROIC(>20%)下的持续有机增长，不需大量资本再投入 |
| 7-8 | ROIC>15%，增长需一定资本投入但回报率高于资本成本 |
| 5-6 | ROIC接近WACC，增长消耗大量资本 |
| 3-4 | ROIC<WACC，增长实际在摧毁价值 |
| 1-2 | 负增长或增长完全依赖并购/举债 |

### 8. 商业可理解性（5%）

| 分数 | 描述 |
|------|------|
| 9-10 | 一句话说清：卖什么、赚谁的钱、为什么有利润 |
| 7-8 | 可以向非专业人士解释清楚 |
| 5-6 | 需要行业背景才能理解，但逻辑清晰 |
| 3-4 | 商业模式复杂或高度技术化 |
| 1-2 | 连行业专家也难以说清盈利模式 |

### 9. 护城河多样性（4%）

| 分数 | 描述 |
|------|------|
| 9-10 | 同时拥有3种以上强力护城河 |
| 7-8 | 拥有2种强力护城河 |
| 5-6 | 拥有1种强力护城河 + 1种次要护城河 |
| 3-4 | 仅有1种中等强度护城河 |
| 1-2 | 无明确护城河或护城河极弱 |

### 10. 长期持有适宜性（3%）

| 分数 | 描述 |
|------|------|
| 9-10 | 如果股市关闭20年，完全不担心——公司会更强 |
| 7-8 | 10年后大概率更强，但存在轻微不确定性 |
| 5-6 | 5年内可能不错，但长期受技术变革威胁 |
| 3-4 | 行业在转型期，长期前景不明 |
| 1-2 | 行业在衰落或公司面临被颠覆风险 |

## 综合评分计算

```
综合分 = Σ (各维度得分 × 权重)
```

| 综合分 | 巴菲特评级 | 含义 |
|--------|-----------|------|
| ≥ 8.0 | **Strong Buy** | "以合理价格买入极好的公司" — 重仓买入 |
| 6.5-7.9 | **Buy** | 好公司+合理价格，值得建仓 |
| 5.0-6.4 | **Hold** | 公司不错但价格不够便宜，等待回调 |
| < 5.0 | **Pass** | 放入"太难"一堆 — 巴菲特会跳过 |

**特殊规则**：
- 护城河持久性 < 5 → 无论综合分多高，最高评级为 Hold
- 管理层品质 < 3（品格红旗）→ 直接评级 Pass
- 安全边际 < 3（高估）→ 最高评级为 Hold
